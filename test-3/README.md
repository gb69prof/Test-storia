# Test concettuale - Seconda guerra mondiale

Pacchetto pronto per GitHub Pages.

## Contenuto

- `index.html`: pagina principale del test.
- `questions.js`: banca delle 20 domande concettuali.
- `manifest.webmanifest`: file PWA.
- `sw.js`: service worker per cache base.

## Funzioni

- 20 domande a risposta multipla.
- 4 risposte per ogni domanda.
- Una sola risposta corretta.
- Ordine delle domande randomizzato a ogni avvio.
- Ordine delle risposte randomizzato a ogni avvio.
- Report finale con voto in decimi.
- Salvataggio del risultato con nome nel browser.
- Esportazione risultati in CSV.
- Download del report individuale.

## GitHub Pages

Carica tutti i file in una cartella del repository, ad esempio:

`Test-3/`

Poi apri:

`https://gb69prof.github.io/Test-storia/Test-3/`
